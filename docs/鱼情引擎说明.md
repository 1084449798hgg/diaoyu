# 鱼情引擎 v1 说明

对应需求文档第八节。**分鱼种多因子加权规则引擎**（不做 ML）：可解释、可配置、冷启动可用。

## 一、模型结构

```
score = Σ(weight_i × factor_score_i) / Σ(weight_i)     # 加权平均，clamp 0-100
```

- 权重按鱼种配置，存于 `fish_species_config.weights_json`，**加鱼种不改代码**
- 每个因子输出 0-100 分与一句人类可读解释（`label`）
- 总分映射等级：**≥82 窗口期 / ≥68 较好 / ≥52 一般 / <52 冷**
- 最佳时间窗：优先取「窗口期」最长连续段，逐级降档
- Top 2-3 影响因子：对窗口内得分偏离基准(70)贡献最大者，标注正/负向

## 二、因子与打分规则

| 因子 | 权重示例（鲫鱼） | 规则 |
|---|---|---|
| `pressure_absolute` 气压绝对值 | 0.15 | 1000-1020hPa 舒适区 = 100；低于 1000 每 hPa -9，高于 1020 每 hPa -6 |
| `pressure_trend` 气压趋势 | 0.20 | **3h 下降 >5hPa 后 1h 内趋稳 = 95（窗口信号）**；骤降进行中 65；缓降 80；平稳 70；持续上升最低 25 |
| `wind` 风力 | 0.15 | 1.6-3.3m/s（二级风）= 100；无风线性降（最低 50）；3.3-5 缓降；5-8 降至 25-60；**>8m/s 安全风险，≤25 分** |
| `water_temp` 水温估算 | 0.30 | 估算值在鱼种适宜区间 = 100，每偏离 1℃ -16 分 |
| `precipitation` 降水 | 0.10 | 微雨 0.1-4mm/h = 92（刺激活动）；无雨 62；中雨 55；暴雨 ≤30 |
| `moon_tide` 月相/潮汐 | 0.10 | 海钓权重高（大潮期 +50）；淡水低权重（65±12） |

## 三、水温估算

水体具有热惯性，不直接用当前气温：

```
water_temp ≈ 过去 12h 平均气温 − 水域深度偏移
```

深度偏移按水域类型配置：水库 4℃ / 湖泊 2.5℃ / 河流 2℃ / 黑坑 1.5℃ / 近海 1℃。

## 四、鱼种配置（`fish_species_config` 表）

| 鱼种 | 类别 | 适宜水温 | 权重特点 |
|---|---|---|---|
| 鲫鱼 | 淡水 | 15-25℃ | 均衡，水温权重最高 0.30 |
| 鲤鱼 | 淡水 | 20-28℃ | 水温 0.35，喜高温 |
| 草鱼 | 淡水 | 22-30℃ | 降水 0.20，微雨活跃 |
| 鲢鳙 | 淡水 | 20-30℃ | 降水 0.25，热天旺 |
| 翘嘴 | 淡水 | 18-28℃ | 气压趋势+风力各 0.20，早晚窗口明显 |
| 罗非鱼 | 淡水 | 24-32℃ | 水温 0.45，怕冷 |
| 海鲈鱼 | 海钓 | 15-26℃ | **月相潮汐 0.35** |

新增鱼种只需 INSERT 一行配置，引擎自动生效。

## 五、数据流与缓存

```
请求 /forecast
   ├─ Redis 缓存命中？──────────────→ 返回（meta.source = cache）
   ├─ MySQL 当日快照未过期？────────→ 返回（meta.source = snapshot）
   └─ 实时计算
        ├─ 天气：Redis weather:{spotId}:{date}（TTL 1h + 0-30s jitter）
        │     未命中 → 和风 API（已配置 KEY）/ 内置模拟器
        │     数据源失败 → 降级模拟器（meta.degraded = true）
        ├─ 六因子加权计算 + Top 因子提取
        ├─ 写入 forecast_snapshots（唯一索引 spot+date+species，过期时间当天 23:59）
        └─ 写 Redis forecast:{spotId}:{date}:{species}（TTL 至当天 23:59）
```

## 六、可解释性输出示例

```
最佳窗口 17:00 - 23:59（均分 86，窗口期）

Top 影响因子：
  👍 水温约 15.4℃，处于鲫鱼适宜区间 15.0-25.0℃        [因子分 100]
  👍 气压 1002.6hPa，处于鱼类舒适区                      [因子分 100]
  👍 东南风二级（2.7m/s）                              [因子分 100]
```

## 七、校准闭环（FR-05）

个人日志记录「出钓时间 + 环境参数（天气快照）+ 是否上鱼」，存入 `fishing_logs`，作为后续模型校准与 ML 版本（v2）的训练数据来源。
